# ตั้งค่าแจ้งเตือนกลุ่ม LINE เจ้าหน้าที่

ระบบใช้ LINE Official Account และ Messaging API ผู้ดูแลตั้งค่าผ่าน `/manage?view=line` เท่านั้น สหกรณ์ยังส่งปัญหาทางหน้าเว็บได้ตามเดิม

## สำหรับผู้ที่ยังไม่มีบัญชี

1. สร้าง LINE Official Account ที่ https://manager.line.biz/ แล้วเปิดใช้ Messaging API ตามคู่มือ https://developers.line.biz/en/docs/messaging-api/getting-started/
2. ใน LINE Developers Console ของบัญชีนี้ เปิดตัวเลือก Allow bot to join group chats ออก Channel access token และคัดลอก Channel secret
3. เข้าหน้าผู้ดูแล → แจ้งเตือน LINE กรอกรหัสทั้งสองในช่องรหัสลับ บันทึก แล้วกดตรวจสอบบัญชี ห้ามส่งรหัสเหล่านี้ในแชต
4. ตั้ง Webhook URL เป็น `https://cad-support-desk-nov26.sarayuthphh.chatgpt.site/api/line/webhook` กด Verify และเปิด Use webhook
5. เชิญบัญชี OA เข้ากลุ่มเจ้าหน้าที่ แล้วส่งข้อความใดก็ได้ในกลุ่ม กลับมาหน้าตั้งค่าและกดโหลดรายชื่อกลุ่ม ระบบตรวจลายเซ็น Webhook และไม่เก็บข้อความสนทนา
6. เลือกกลุ่ม กดส่งทดสอบ ตรวจสอบข้อความในกลุ่ม แล้วเปิดแจ้งเตือนเรื่องใหม่ ระบบไม่เลือกกลุ่มหรือเปิดใช้งานเอง

หากเชิญบัญชีไม่ได้ ให้ตรวจการอนุญาตเข้ากลุ่มและข้อจำกัดบัญชีใน [คู่มือกลุ่ม LINE](https://developers.line.biz/en/docs/messaging-api/group-chats/)

## การทำงาน

- หลังบันทึกเรื่องใหม่สำเร็จ จะส่งเลขอ้างอิง สหกรณ์ โปรแกรม ประเภทเรื่อง ความเร่งด่วน หัวข้อ และลิงก์งานสำหรับเจ้าหน้าที่ ไม่ส่งรายละเอียดปัญหา เบอร์โทร อีเมล หรือไฟล์แนบไป LINE หัวข้อเรื่องจึงควรหลีกเลี่ยงข้อมูลส่วนบุคคล
- เจ้าหน้าที่ต้องเข้าสู่ระบบก่อนเปิดดูรายละเอียดจากลิงก์
- บันทึกเรื่องและรายการแจ้งเตือนพร้อมกันในฐานข้อมูล ถ้า LINE ล่ม เรื่องที่สหกรณ์ส่งยังคงอยู่
- “LINE รับคำขอแล้ว” หมายถึง API ยอมรับคำขอ ไม่ใช่หลักฐานว่าเจ้าหน้าที่อ่านหรือได้รับข้อความแล้ว
- ผู้ดูแลตรวจผลและกดลองส่งอีกครั้งได้ ระบบใช้ retry key เดิมและข้อความเดิมเพื่อป้องกันการส่งซ้ำภายใน 23 ชั่วโมงจากครั้งแรก ไม่ส่งซ้ำเมื่อ LINE ยืนยันว่ารับคำขอแล้ว และไม่เปลี่ยนกลุ่มหรือบัญชีให้รายการเดิม
- ไม่มีการส่งย้อนหลังอัตโนมัติหรือการลองส่งซ้ำตามเวลา รายการที่รอตั้งค่าต้องให้ผู้ดูแลเลือกส่งเองหลังเปิดใช้งาน
- เมื่อ OA ออกจากกลุ่ม ระบบปิดแจ้งเตือน ต้องเชิญกลับ เลือกกลุ่ม และทดสอบใหม่
- ตรวจสอบโควตาหรือแพ็กเกจส่งข้อความในบัญชี OA ของหน่วยงาน

## รหัสลับและการดูแลระบบ

Token และ Channel secret ถูกเข้ารหัส AES-256-GCM ก่อนเก็บใน D1 และไม่ถูกส่งคืนผ่าน API ตัวแปรลับ `LINE_SETTINGS_KEY` ต้องเป็นคีย์ base64 ขนาด 32 ไบต์ เก็บสำรองให้ปลอดภัย การเปลี่ยนคีย์โดยไม่เข้ารหัสข้อมูลเดิมใหม่จะทำให้อ่านรหัสเชื่อมต่อไม่ได้ เว็บไซต์จริงตั้งคีย์นี้ไว้แล้ว แต่ยังต้องสร้างและเชื่อมบัญชี OA ของหน่วยงาน

`LINE_API_BASE_URL` ใช้ทดสอบกับ localhost เท่านั้น เว็บไซต์จริงใช้ API ทางการของ LINE เสมอ

## การทดสอบในเครื่อง

สคริปต์ `scripts/mock-line.mjs` จำลอง API โดยไม่มีการส่งไป LINE จริง ส่วน `scripts/verify-line.mjs` ตรวจบันทึกเรื่อง การตั้งค่า ลายเซ็น Webhook การส่งล้มเหลว การส่งซ้ำ ลิงก์งาน และหน้าจอมือถือ การทดสอบนี้ไม่ทดแทนการส่งทดสอบในกลุ่มจริงหลังเชื่อมบัญชี
